# Data handling

Begin with synthetic data generated by the project. For empirical datasets, document provenance, permissions, units, construction and sample selection.

- \`data/raw/\` and \`data/processed/\` are ignored by Git.
- Do not commit restricted IFLS microdata or identifiable person-level information.
- Keep only metadata, original code, permitted codebooks and reproducible build scripts.
- Use \`data/raw/\` locally for private data, and never include secrets in scripts.
- An empirical research application should document data cleaning, attrition, variable timing and survey design.
